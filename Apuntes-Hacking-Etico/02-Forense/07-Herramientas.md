# Herramientas de Forense

| Herramienta | Para qué sirve | Enlace / instalación |
|---|---|---|
| `file` | Identificar el tipo real de un archivo | Preinstalado en Linux |
| `xxd` | Ver el volcado hexadecimal de un archivo (firmas) | Preinstalado en Linux |
| exiftool | Leer y extraer metadatos de imágenes, documentos, audio | https://exiftool.org/ |
| Wireshark | Analizar capturas de tráfico de red (.pcap) | https://www.wireshark.org/download.html |
| Volatility 3 | Analizar volcados de memoria RAM | https://github.com/volatilityfoundation/volatility3 |
| Autopsy | Análisis forense de imágenes de disco completas (archivos borrados, timeline) | https://www.sleuthkit.org/autopsy/ |
| binwalk | Detectar/extraer archivos ocultos embebidos dentro de otro archivo | https://github.com/ReFirmLabs/binwalk |
| `strings` | Extraer texto legible de cualquier archivo binario | Preinstalado en Linux |
| CyberDefenders | Plataforma de práctica con casos forenses reales | https://cyberdefenders.org/ |
| NetworkMiner | Alternativa a Wireshark, orientada a reconstrucción de archivos/artefactos | https://www.netresec.com/?page=NetworkMiner |
| Foremost / PhotoRec | Recuperar archivos borrados o "carving" dentro de una imagen de disco | PhotoRec: https://www.cgsecurity.org/wiki/TestDisk_Download |
| Bulk Extractor | Extraer emails, URLs, tarjetas, etc. de una imagen forense de forma masiva | https://github.com/simsong/bulk_extractor |
