# Herramientas de Miscelánea

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| Python 3 | Base para automatizar prácticamente cualquier reto | https://www.python.org/ |
| pwntools | Conectarse a servicios remotos y automatizar exploits | https://github.com/Gallopsled/pwntools |
| netcat (nc) | Conectarse a servicios remotos manualmente | Preinstalado en Linux |
| CyberChef | También cubre gran parte de "misc" (encodings raros, compresión, etc.) | https://cyberchef.org/ |
| 7-Zip / unrar / unzip | Descomprimir formatos poco comunes o con contraseña | https://www.7-zip.org/ (Linux: `apt install p7zip-full unrar unzip`) |
| `strings` / `file` | Primer diagnóstico rápido de cualquier archivo desconocido | Preinstalados en Linux |
| HackTheBox "Challenges" | Retos de Misc filtrables por dificultad | https://www.hackthebox.com/ |
| CyLab Academy | Retos de Misc organizados por dificultad (ex picoCTF) | https://learn.cylabacademy.org/ |
