# Para investigar después — Miscelánea

- **Buffer Overflow explicado paso a paso**: si un reto de Misc resulta ser de explotación de memoria, este es el punto de entrada clásico para entenderlo desde cero.
  https://ropemporium.com/guide.html

- **ROP Emporium**: serie progresiva de retos para aprender Return-Oriented Programming, la técnica de explotación de binarios más común después del buffer overflow básico.
  https://ropemporium.com/

- **Programación competitiva básica (para los "puzzles" de Misc)**: algunos retos de Misc son en realidad pequeños problemas algorítmicos — practicar en plataformas de programación competitiva ayuda a resolverlos más rápido.
  https://www.hackerrank.com/

- **Automatización avanzada con pwntools (plantillas de exploit)**: pwntools tiene un generador de plantillas (`pwn template`) que arma la estructura base de un exploit automáticamente.
  https://docs.pwntools.com/en/stable/

- **pwn.college**: plataforma gratuita con cursos progresivos de explotación de sistemas Linux, muy recomendada para profundizar en la parte "pwn" de Miscelánea.
  https://pwn.college/
