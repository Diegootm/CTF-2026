# Herramientas de Esteganografía

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| exiftool | Revisar metadatos — siempre el primer paso | https://exiftool.org/ |
| StegOnline | Analizar imágenes por capas/canales/LSB, sin instalar nada | https://stegonline.georgeom.net/upload |
| Stegsolve | Alternativa clásica a StegOnline, con interfaz de escritorio | Buscar "Stegsolve.jar" en GitHub |
| zsteg | Detección automática de LSB en imágenes PNG/BMP | https://github.com/zed-0xff/zsteg |
| steghide | Ocultar/extraer archivos en JPG/BMP/WAV/AU, con o sin contraseña | http://steghide.sourceforge.net/ |
| stegcracker | Fuerza bruta de contraseñas contra archivos de steghide | https://github.com/Paradoxis/StegCracker |
| binwalk | Detectar y extraer archivos ocultos embebidos en cualquier formato | https://github.com/ReFirmLabs/binwalk |
| Aperi'Solve | Corre varias herramientas de stego a la vez sobre una imagen (binwalk, zsteg, exiftool) | https://www.aperisolve.com/ |
| Audacity | Ver espectrogramas de archivos de audio | https://www.audacityteam.org/download/ |
| zbarimg | Decodificar códigos QR ocultos o dañados | Paquete `zbar-tools` (`apt install zbar-tools`) |
