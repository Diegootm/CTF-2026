# Herramientas de OSINT

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| Google Dorks | Búsquedas avanzadas en Google | No requiere instalación, se usa desde el buscador |
| theHarvester | Correos, subdominios, IPs, hosts asociados a un dominio | https://github.com/laramies/theHarvester |
| Holehe | Verificar en qué plataformas está registrado un correo | https://github.com/megadose/holehe |
| Sherlock | Buscar un nombre de usuario en decenas de redes sociales | https://github.com/sherlock-project/sherlock |
| Google Images / Yandex Images | Búsqueda inversa de imágenes | https://images.google.com/ y https://yandex.com/images/ |
| TinEye | Búsqueda inversa especializada en origen de imágenes | https://tineye.com/ |
| Wayback Machine | Ver versiones antiguas de un sitio web | https://web.archive.org/ |
| Whois | Información de registro de un dominio | https://who.is/ |
| crt.sh | Certificados SSL — descubrir subdominios | https://crt.sh/ |
| TraceLabs | Metodología y CTFs enfocados en OSINT (búsqueda de personas) | https://tracelabs.org/ |
| Maltego (community) | Visualizar relaciones entre entidades (dominios, personas, IPs) | https://www.maltego.com/downloads/ |
| GeoGuessr | Practicar geolocalización a partir de imágenes | https://www.geoguessr.com/ |
