# Herramientas de Reversing

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| `file` | Identificar tipo de archivo (ELF/PE, 32/64 bits) | Preinstalado en Linux |
| `strings` | Extraer texto legible de un binario | Preinstalado en Linux |
| Ghidra | Desensamblador/decompilador gratuito, el estándar de la industria | https://ghidra-sre.org/ |
| gdb | Depurador de binarios en Linux | Preinstalado en la mayoría de distros |
| pwndbg | Extensión de gdb con información visual útil | https://github.com/pwndbg/pwndbg |
| GEF | Alternativa a pwndbg para gdb | https://github.com/hugsy/gef |
| Cutter | Interfaz gráfica de radare2, alternativa más liviana a Ghidra | https://cutter.re/ |
| Radare2 | Framework de reversing en terminal, más rápido para binarios pequeños | https://github.com/radareorg/radare2 |
| crackmes.one | Binarios para practicar reversing de distintos niveles | https://crackmes.one/ |
| pwntools (Python) | Automatizar interacción con binarios/exploits | https://github.com/Gallopsled/pwntools |
