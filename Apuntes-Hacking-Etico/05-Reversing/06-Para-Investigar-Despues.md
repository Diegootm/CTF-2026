# Para investigar después — Reversing

- **Ingeniería inversa de binarios con protecciones (Anti-Debug, packers como UPX)**: técnicas que dificultan el análisis a propósito, y cómo sortearlas.
  https://github.com/guyinatuxedo/nightmare (recurso "Nightmare", curso gratuito de binary exploitation/reversing progresivo)

- **ROP (Return-Oriented Programming)**: técnica avanzada de explotación de binarios que reutiliza fragmentos de código existente para lograr ejecución de código arbitrario — más de la rama "pwn" que de reversing puro, pero comparten mucha base.
  https://ropemporium.com/

- **Ingeniería inversa de Android (APKs)**: si algún reto da un archivo `.apk`, el proceso de análisis es distinto (herramientas como jadx, apktool).
  https://github.com/skylot/jadx

- **Ofuscación de código y cómo desofuscar**: técnicas que los desarrolladores usan para hacer el código más difícil de leer, y estrategias generales para revertirlas.
  https://github.com/guyinatuxedo/nightmare

- **pwn.college**: plataforma gratuita centrada específicamente en binary exploitation y reversing, con progresión de dificultad muy bien pensada.
  https://pwn.college/
