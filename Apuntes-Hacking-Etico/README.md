#  Apuntes de Hacking Ético 

Apuntes organizados por área, pensados para encontrar rápido lo que necesiten repasar antes o durante la práctica. Cada carpeta tiene su propio `00-Indice.md` que explica qué hay en cada archivo.

## Cómo usar esto
- Si quieren **aprender una teoría desde cero**, entren a la carpeta del área y sigan los archivos en el orden numerado (01, 02, 03...) — están ordenados de lo más básico a lo más avanzado.
- Si ya saben lo básico y solo quieren **repasar algo puntual**, usen el índice de cada carpeta para saltar directo al tema.
- Cada área tiene un archivo `Herramientas.md` con todo lo que necesitan instalar/usar, y un archivo `Para-Investigar-Despues.md` con temas que vale la pena profundizar más adelante (con el link y una línea de qué trata, sin desarrollar la teoría).
