# Herramientas de Seguridad de Redes

| Herramienta | Para qué sirve | Enlace / instalación |
|---|---|---|
| nmap | Escaneo de puertos, servicios, detección de vulnerabilidades básicas | https://nmap.org/download.html |
| Wireshark | Captura y análisis visual de tráfico de red | https://www.wireshark.org/download.html |
| tcpdump | Captura de tráfico desde la terminal, sin interfaz gráfica | Preinstalado en la mayoría de distros Linux |
| netdiscover | Descubrimiento de hosts activos en una red local vía ARP | `sudo apt install netdiscover` |
| dig / nslookup | Consultas DNS manuales | Preinstalados en la mayoría de distros Linux |
| Bettercap | Framework de ataques de red (ARP spoofing, MITM, sniffing) | https://www.bettercap.org/ |
| Ettercap | Alternativa clásica a Bettercap para MITM y sniffing | https://www.ettercap-project.org/ |
| Responder | Captura de credenciales en redes Windows mal configuradas (LLMNR/NBT-NS) | https://github.com/lgandx/Responder |
| enum4linux | Enumeración de servicios SMB en redes Windows | `sudo apt install enum4linux` |
| iptables / ufw | Configurar reglas de firewall en Linux | Preinstalados en la mayoría de distros Linux |
| OpenSSL | Inspeccionar certificados TLS, probar conexiones cifradas manualmente | Preinstalado en la mayoría de distros Linux |
| Shodan | Buscador de dispositivos/servicios expuestos en internet | https://www.shodan.io/ |
