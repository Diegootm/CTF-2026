# Para investigar después — Seguridad de Redes

- **Pivoting y movimiento lateral**: técnicas para "saltar" de una red/segmento comprometido a otro, usando el host ya comprometido como puente. Muy relevante en retos avanzados que simulan redes empresariales completas.
  https://book.hacktricks.xyz/generic-methodologies-and-resources/pivoting

- **Active Directory (AD) — ataques comunes**: si en algún momento aparece un entorno Windows corporativo (Kerberoasting, Pass-the-Hash), es un área enorme por sí sola con su propia metodología.
  https://www.thehacker.recipes/ad/

- **IDS/IPS (Sistemas de Detección/Prevención de Intrusos)**: cómo funcionan las herramientas defensivas que detectan patrones de ataque en tiempo real (ej. Snort, Suricata), y técnicas de evasión.
  https://suricata.io/

- **Túneles y exfiltración de datos por protocolos "permitidos"**: técnicas como DNS tunneling o ICMP tunneling, que esconden tráfico dentro de protocolos que normalmente se permiten a través de firewalls.
  https://book.hacktricks.xyz/generic-methodologies-and-resources/tunneling-and-port-forwarding

- **HackTricks**: una de las wikis más completas y gratuitas sobre metodologías de pentesting de redes, con ejemplos prácticos de casi cualquier escenario.
  https://book.hacktricks.xyz/
