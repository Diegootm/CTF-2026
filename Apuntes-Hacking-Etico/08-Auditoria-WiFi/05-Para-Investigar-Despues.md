# Para investigar después — Wi-Fi

- **Ataques a WPA3 (Dragonblood)**: aunque WPA3 mitiga los ataques clásicos, se han descubierto vulnerabilidades específicas en su protocolo SAE — tema avanzado y en evolución.
  https://wpa3.mathyvanhoef.com/

- **Evil Twin Attacks**: crear un punto de acceso falso que imita a uno legítimo, para interceptar credenciales de usuarios que se conecten por error.
  https://www.aircrack-ng.org/doku.php?id=airbase-ng

- **Aircrack-ng suite completa**: el conjunto de herramientas clásico para auditoría Wi-Fi (más granular que Wifite, útil para entender cada paso individualmente).
  https://www.aircrack-ng.org/

- **Bluetooth y otros protocolos inalámbricos**: los mismos principios de auditoría (captura, análisis offline) aplican con herramientas distintas a otros protocolos como Bluetooth o Zigbee.
  https://github.com/greatscottgadgets/ubertooth
